Remarks

Its output is whatever feeds the inner graph's output node, in the inner graph's domain. Its inputs are the inner input ports it exposes, and its editable properties are its Name plus the inner properties it exposes, each under its own name. Evaluation never sees a composite: Flattened replaces it with the nodes inside it first.
