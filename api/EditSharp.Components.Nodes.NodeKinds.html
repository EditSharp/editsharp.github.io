Remarks

Enabled, and every [Editable] property the new kind has under the same name and type, keyframes included, carry over; the rest takes the kind's defaults. A media or a nested timeline is shared, not copied. Wires and exposures follow ReplaceNode(Node, Node). Each change is recorded in the current History transaction.

Exceptions

ArgumentException

node isn't in a graph, or kind can't be made from scratch.

InvalidOperationException

The new kind can't take the node's place; see ReplaceNode(Node, Node).
