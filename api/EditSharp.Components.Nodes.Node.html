Animatables

Every keyframeable property this node owns, so a clip can reach all of its tracks at once — a head trim/extend shifts every keyframe in the graph (see Clip.OnHeadInPointShift). Empty by default; a node with Animatable properties overrides it and lists each one. An animated property left out here simply stops following the content when the clip's head moves.
