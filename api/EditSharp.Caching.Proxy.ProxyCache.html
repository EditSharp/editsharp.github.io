Remarks

An original is identified by a hash of its content, so a renamed, moved or copied file finds the same proxy. Nothing builds automatically: call BuildAsync(string, ProxyFormat?, IProgress<double>?, HardwareAccelerator, CancellationToken) (typically on import) and watch StatusChanged; everything that reads media only looks proxies up. A proxy can be read up to AvailableUpTo while it builds, stays readable if the build is interrupted, and the next build resumes it. Building a different format replaces the proxy: the old one serves reads until the new one completes, then is deleted.

Proxies live under ProxyDirectory, in a folder named after the first two characters of the hash. Each format has its own file stem (hash.delta7, .rgba, .dnxhr, .prores): .esrp proxies are one .esrp file, and MOV proxies are a .mov.json sidecar plus numbered segments while building and one .mov once complete.

Remarks

Finishes at once if a complete proxy in that format exists. Several callers asking for the same file share one build. Cancelling only detaches this caller; the build stops when no caller is left, and what it wrote stays readable and resumable.
