Remarks

Inputs: A and B, plus optional Value inputs MixAModulation and MixBModulation that multiply MixA and MixB. Output: Result. Use it to combine two sources in one clip, or for parallel processing, such as mixing a heavily compressed copy under the dry signal.

Remarks

The default passes the first input through, or writes silence for a node with no audio input. A node that changes audio overrides this so waveform displays show its effect without rendering samples. A node that carries state between frames (a compressor's envelope) keeps it in state.
