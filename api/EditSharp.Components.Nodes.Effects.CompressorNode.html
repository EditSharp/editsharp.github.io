DescribeSpectrum(in SpectralContext, ReadOnlySpan<SpectralFrame>, SpectralFrame, ref object?)

Describes what the node does to audio in the frequency domain, for one frame.

public override void DescribeSpectrum(in SpectralContext context, ReadOnlySpan<SpectralFrame> inputs, SpectralFrame output, ref object? state)

Parameters

context SpectralContext

The frame's content time and length.

inputs ReadOnlySpan<SpectralFrame>

One frame per audio input port, in port order; an unwired input is silence.

output SpectralFrame

The frame to write the node's output into.

state object

Whatever the node kept from the previous frame; null on the first.

Remarks

The default passes the first input through, or writes silence for a node with no audio input. A node that changes audio overrides this so waveform displays show its effect without rendering samples. A node that carries state between frames (a compressor's envelope) keeps it in state.
