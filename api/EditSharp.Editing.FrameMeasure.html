How a value measures against the frame, so an editor can show it in pixels of the render resolution. Stored values stay frame-relative, which keeps a project independent of its canvas size.

public enum FrameMeasure

Fields

Frame = 2

A size: x as a fraction of the frame width, y of its height.

HalfFrame = 3

A position or offset: x in half frame widths, y in half heights, up positive; 0 is the centre.

None = 0
Width = 1

A length, as a fraction of the frame width.
