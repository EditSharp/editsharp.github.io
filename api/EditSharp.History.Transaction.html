Remarks

The model reports each primitive write as it happens (Set<TOwner, T>(TOwner, ref T, T, Action<TOwner, T>, string) for a property, Apply(Action, Action, string) for anything else). A user action opens a transaction with Begin(string), makes its edits and commits; the writes in between become one entry, and undo replays them backwards on the same objects. A write with no transaction open becomes an entry of its own in Active, or goes unrecorded when there is no active history. Writes made while building objects that aren't in the project yet go through Suppress(). Write from the main thread only.
