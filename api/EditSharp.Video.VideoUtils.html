MuxAudioVideoAsync(MediaVideoSource, MediaAudioSource, string)

Joins a video and an audio source into one file without re-encoding either.

public static Task<MediaVideoSource> MuxAudioVideoAsync(MediaVideoSource video, MediaAudioSource audio, string outputPath)

Parameters

video MediaVideoSource

The video source; its video stream is used.

audio MediaAudioSource

The audio source; its audio stream is used.

outputPath string

The file to write; its extension picks the container.

Returns

Task<MediaVideoSource>

A source for the new file.

Remarks

Both streams are copied, so it's fast, but the output container must accept both codecs as they are. Each source's Start and Duration trim it, landing on the nearest keyframe. The output ends with the shorter stream.

Exceptions

FileNotFoundException

Either input doesn't exist.

InvalidOperationException

ffmpeg failed.

ReencodeVideoAsync(MediaVideoSource, VideoCodec, (int Width, int Height)?)

Re-encodes a source's video to another codec, optionally resized, with no audio.

public static Task<string> ReencodeVideoAsync(MediaVideoSource source, VideoCodec codec, (int Width, int Height)? scaleTo = null)

Parameters

source MediaVideoSource

The source to re-encode.

codec VideoCodec

The codec to encode with.

scaleTo (int Width, int Height)?

The exact output size, already aspect-correct; null keeps the source's size.

Returns

Task<string>

The path of the new file.

Remarks

The source's Start and Duration trim it frame-accurately, since ffmpeg decodes from the nearest keyframe to the exact time. The file goes under TempDirectory.

Exceptions

FileNotFoundException

The source file doesn't exist.

NotSupportedException

codec has no encoder.

InvalidOperationException

ffmpeg failed.
