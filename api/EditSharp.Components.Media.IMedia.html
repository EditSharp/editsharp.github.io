Remarks

A media knows nothing about clips or nodes. It reports how long its material is and opens readers on it in its own time, from the start of the material; the input node holding it maps the clip's content time to that. Any number of nodes, in any number of clips, can share one media, and UsedBy lists them. Nothing prepared or opened is kept on the media.

A media is plain data with history. Its [Editable] properties are exactly what ComponentSerializer saves, and Duplicate() round-trips through it, so a new property is copied exactly when it's saved. Nodes save a media as its Id: a project keeps the media themselves and hands them to the loader.

To add a kind, derive from VideoMedia or AudioMedia, mark the class [MediaKind("stable-id")], and override what differs: how the length is found, how readers are opened. The id is written into saved files, so it must never change. BlenderSceneMedia and VstInstrumentMedia show the bare shape.
