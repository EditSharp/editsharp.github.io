Namespace EditSharp.Components.Sources.Audio

Classes

AudioSource

A source of sound, read as a stream: PrepareAsync does the slow once-per-session work, and the prepared handle opens readers that pull interleaved float samples block by block, already in the format the caller asked for. Mirrors VideoSource's two-phase shape.

MediaAudioSource

The audio stream of a media file on disk (an audio file, or a video file's soundtrack), streamed through ffmpeg. A file with no audio stream reads as silence for its length.

TimelineAudioSource

Another timeline's mixed audio, rendered block by block by its own TimelineAudioRenderer in the reading session. Start/Duration/Loop trim it like any source; its natural length is the timeline's duration. Saved as the timeline's Id (see SourceSerializer.Deserialize).

ToneAudioSource

A synthesized tone. Frequency and amplitude can be keyframed; they're evaluated every sample, and phase carries on across blocks so a changing frequency never clicks.
