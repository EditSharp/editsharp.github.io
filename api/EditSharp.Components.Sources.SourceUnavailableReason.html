Why a source can't provide content right now; compositing picks what to show from this.

public enum SourceUnavailableReason

Fields

DecodeError = 4

The material is there but can't be decoded or rendered.

EndOfSource = 5

The requested time is past the end of the source's window and Loop is off.

MediaOffline = 3

The material is missing or unreadable (a file gone, a device unplugged).

Opening = 0

The reader is still opening and has nothing to hand back yet.

ProxyMissing = 2

The read needs a proxy frame, and no build is queued or running to make it.

ProxyPending = 1

The read needs a proxy frame that a queued or running build hasn't reached yet.
