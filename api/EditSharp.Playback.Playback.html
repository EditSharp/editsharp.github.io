Remarks

Play(TimeSpan?) starts a session: a video loop composites frames on its own GPU context and raises VideoFrame, and the audio engine raises AudioSample. PlaybackMode decides which of the two sets the pace. Pause() holds a session with everything it has open; Stop() ends it. A negative Speed plays in reverse, reading proxies behind the playhead.

ScrubToAsync(TimeSpan, CancellationToken) shows one frame at any position while not playing; rapid calls cancel the ones before, so only the latest is delivered. Scrubbing and thumbnails share a second GPU context kept for this object's life. Sources are read as RenderSettings's SourceMode says; nothing here builds proxies.

ScrubToAsync(TimeSpan, CancellationToken)

Shows the frame at a position, delivered through VideoFrame.

public Task ScrubToAsync(TimeSpan position, CancellationToken ct = default)

Parameters

position TimeSpan

The timeline time to show.

ct CancellationToken

Cancels the scrub; unlike being superseded, this throws.

Returns

Task

Remarks

Safe to call on every pointer move: each call cancels any unfinished one, and a cancelled call completes without an exception. Position moves at once, even if the frame never arrives. Failures are logged, not thrown. A source without a proxy yet shows its placeholder. State is Scrubbing while the frame is composed.

Exceptions

InvalidOperationException

Called while playing.

ArgumentOutOfRangeException

position is outside the timeline.

OperationCanceledException

ct was cancelled.
