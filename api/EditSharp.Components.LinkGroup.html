Remarks

Membership comes from the clips' LinkGroupId, read fresh on every use, so any LinkGroup with the same Id on the same timeline is the same group. A clip is in at most one group. Get one from Link(IEnumerable<Clip>) or GetLinkGroup(Guid?).
