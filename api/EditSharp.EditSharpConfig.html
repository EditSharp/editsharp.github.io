AudioBlockFrames

How many audio frames the engine processes per tick, 32 to 16384.

public static int AudioBlockFrames { get; set; }

Property Value

int

Remarks

Parameter changes take effect within one block; 512 frames is about 10.7 ms at 48 kHz. Read when a session starts.

Exceptions

ArgumentOutOfRangeException

Set outside 32 to 16384.

EsrpCompressionLevel

The Zstd level for .esrp proxy frames, 1 to 22.

public static int EsrpCompressionLevel { get; set; }

Property Value

int

Remarks

Higher is smaller and slower to build: on 1280x720 frames, 9 builds about 18 times faster than 19 for about 10% more disk. Reading speed is the same at any level.

Exceptions

ArgumentOutOfRangeException

Set outside 1 to 22.

FilterThreads

How many threads ffmpeg's filters may use (its -filter_threads and -filter_complex_threads).

public static int FilterThreads { get; set; }

Property Value

int

Remarks

Defaults to 1 because ffmpeg splitting a frame across threads left a one-pixel row of zero alpha at every seam between thread slices, which showed as thin horizontal lines. Raise it only while checking output for those lines.

Exceptions

ArgumentOutOfRangeException

Set below 1.

SwsBackends

Which swscale backends ffmpeg 9 and later may use for scaling and pixel format conversion (its -sws_backends).

public static string SwsBackends { get; set; }

Property Value

string

Remarks

Defaults to "x86", which opts into ffmpeg's SIMD backend; ffmpeg's own default only uses the plain C one. ffmpeg marks x86 unstable, so if output shows seams, banding or wrong alpha, set this to "stable".

TempDirectory

public static string TempDirectory { get; set; }

Property Value

string

Remarks

Defaults to a Temp folder next to the application. Subfolders are created on first write, so the directory doesn't need to exist.

Exceptions

ArgumentNullException

Set to null.
