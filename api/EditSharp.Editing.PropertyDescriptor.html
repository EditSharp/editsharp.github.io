Everything an editor needs to show and change one editable property: its label, control, limits, and how to read and write it.

Remarks

Built once per type from EditableAttribute and the property's own type (see Inspect). Writes go through the property's setter, so they are recorded for undo; list edits are recorded here. A descriptor made with Through(Func<object, object>, string?, string?) reads and writes a property on another object, which is how a composite node shows an inner node's property as its own.
