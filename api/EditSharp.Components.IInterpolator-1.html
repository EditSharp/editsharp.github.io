The arithmetic keyframes need for a value type.

public interface IInterpolator<T>

Type Parameters

T

The type of value.

Remarks

Register one for a new type with Register<T>(IInterpolator<T>); float, Vector2 and SKColor are built in. Handle offsets are values of the type too, so the arithmetic must work outside the type's usual range.
