Interface IInterpolator<T>

Namespace
EditSharp.Components
Assembly
EditSharp.dll

The arithmetic Animatable<T>/KeyframeTrack<T> need to do their job: add/subtract two values (for handle offsets, which are stored as deltas from their keyframe's own value) and blend two values by a normalized progress (for the cubic evaluation itself).

Deliberately a small strategy interface resolved per-T, NOT a self-referential generic constraint (T : IInterpolatable<T>) — the three real payload types this schema keyframes (float, Vector2, SKColor) are all BCL/SkiaSharp types this package doesn't own, so they can't be made to declare an interface themselves. See Interpolators below for the registry that resolves one of these per T.
